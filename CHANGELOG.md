# Changelog

## 0.1.0-beta.1 — October 30, 2026

First public beta for macOS.

- Independent Left, Top, Right and Bottom Feather controls, from zero to the full image dimension.
- Optional top/bottom, left/right and all-side linking, with independent values retained.
- Smooth and linear fade curves.
- Four inset controls to move fade boundaries inward.
- Preservation of existing transparency.
- Universal Intel and Apple silicon build; live qualification on Premiere Pro 26.5.2 / Intel.
- MIT-licensed source, reproducible build scripts and core/buffer tests.
- Developer ID signed plug-in and installer; Apple notarization is not completed for this initial beta.
